# Características de AbanQ

## Descripción General

AbanQ es un ERP (Enterprise Resource Planning) modular diseñado específicamente para pequeñas y medianas empresas (PYMES). Ofrece todas las herramientas necesarias para gestionar los procesos comerciales principales.

---

## 1. Módulo de Contabilidad

### Funcionalidades

- **Contabilidad financiera**: Registro de operaciones contables según normas fiscales
- **Plan de cuentas**: Personalizable según necesidades de la empresa
- **Diarios**: Generales, de ventas, de compras, de caja y banco
- **Mayor contable**: Consultas de movimientos por cuenta
- **Conciliación bancaria**: Automatizada para reconciliar bancos
- **Análisis de cuentas**: Balances, pérdidas y ganancias, informes personalizados

### Ventajas

- Cumplimiento con normativas fiscales
- Auditoría y trazabilidad completa
- Informes contables profesionales
- Exportación a formatos estándar (CSV, PDF)

---

## 2. Módulo de Facturación

### Funcionalidades

- **Facturas de venta**: Creación, edición y anulación
- **Facturas de compra**: Recepción y gestión de facturas de proveedores
- **Notas de crédito/débito**: Para ajustes y devoluciones
- **Numeración automática**: Según normativas fiscales
- **Personalización**: Logo, términos, condiciones de pago
- **Impresión y exportación**: PDF, impresora térmica o tradicional

### Características avanzadas

- Descuentos por línea o documento
- Cálculo automático de impuestos (IVA, etc.)
- Histórico de versiones de facturas
- Vinculación automática con contabilidad

---

## 3. Módulo de Inventario

### Funcionalidades

- **Gestión de almacenes**: Múltiples almacenes con transfers entre ellos
- **Stock de artículos**: Control de existencias en tiempo real
- **Movimientos**: Entrada, salida, ajustes de inventario
- **Alertas de stock**: Notificaciones cuando el stock es bajo
- **Códigos de barras**: Soporte para lectura de códigos
- **Categorías y subcategorías**: Organización flexible de productos

### Características

- Valoración de inventario (FIFO, LIFO, medio ponderado)
- Histórico de movimientos
- Informes de rotación
- Auditoría de cambios en stock

---

## 4. Módulo de Compras

### Funcionalidades

- **Órdenes de compra**: Creación y seguimiento
- **Gestión de proveedores**: Base de datos de proveedores
- **Presupuestos**: Recepción y comparativa de presupuestos
- **Recepción de mercancía**: Entrada de productos
- **Cancelación de compras**: Manejo de devoluciones
- **Análisis de proveedores**: Rendimiento y historial

### Características

- Condiciones de pago configurables
- Avisos de pedidos pendientes
- Cálculo automático de costos
- Integración con facturación de compras

---

## 5. Módulo de Ventas

### Funcionalidades

- **Presupuestos**: Creación de presupuestos para clientes
- **Pedidos**: Órdenes de venta
- **Albaranes**: Documentos de entrega
- **Gestión de clientes**: Base de datos de clientes
- **Historial de ventas**: Análisis del comportamiento de compra
- **Seguimiento de pedidos**: Estado en tiempo real

### Características

- Control de crédito del cliente
- Avisos de clientes con deuda vencida
- Análisis de comisiones
- Vinculación automática con almacén

---

## 6. Módulo de Tesorería

### Funcionalidades

- **Caja**: Control de movimientos de efectivo
- **Bancos**: Gestión de cuentas bancarias
- **Pagos y cobros**: Registro de transacciones
- **Préstamos**: Control de financiamientos
- **Flujo de caja**: Proyecciones y análisis
- **Transferencias**: Entre cuentas

### Reportes

- Posición de caja
- Posición de bancos
- Previsión de flujo de caja
- Análisis de liquidez

---

## 7. Módulo de Informes

### Tipos de reportes

- **Financieros**: Balance general, estado de resultados, flujo de caja
- **Operacionales**: Ventas, compras, inventario
- **Fiscales**: Para presentación a autoridades
- **Personalizados**: Creación de reportes a medida

### Características

- Gráficos interactivos
- Exportación a múltiples formatos (PDF, Excel, CSV)
- Filtros y parámetros dinámicos
- Programación de reportes automáticos

---

## 8. Características Transversales

### Seguridad

- **Autenticación**: Usuario y contraseña
- **Perfiles de usuario**: Control de acceso granular
- **Auditoría**: Registro de todas las operaciones
- **Backup**: Funciones de respaldo automático
- **Cifrado**: De datos sensibles

### Escalabilidad

- **Múltiples usuarios**: Soporte para acceso concurrente
- **Múltiples empresas**: Gestión de varios negocios
- **Bases de datos distribuidas**: Soporte para infraestructuras complejas
- **Performance**: Optimizado para grandes volúmenes de datos

### Flexibilidad

- **Personalizaciones**: Modificación de campos y formularios
- **Extensibilidad**: Desarrollo de nuevos módulos
- **Integraciones**: Conectores para sistemas externos
- **API**: Para desarrollo de integraciones

---

## 9. Características Técnicas

### Plataformas soportadas

- **Windows**: XP SP3 y posteriores
- **Linux**: Cualquier distribución moderna (Ubuntu, Debian, Fedora, etc.)
- **macOS**: 10.5 y posteriores

### Bases de datos soportadas

- PostgreSQL (recomendado para producción)
- MySQL
- SQLite (para desarrollo/pequeños usuarios)

### Tecnologías

- **C++**: Motor principal
- **Qt Framework**: Interfaz gráfica
- **Qt Script**: Scripting para extensiones
- **XML/JSON**: Para datos e integraciones
