# AbanQ ERP Software

> 🚀 Software libre y modular para la gestión integral de empresas

---

## Sobre AbanQ

**AbanQ** es un sistema de planificación de recursos empresariales (ERP) modular, flexible y de código abierto. Desarrollado bajo licencia GPL-2.0, ofrece soluciones completas para la gestión de operaciones comerciales, contabilidad y recursos en empresas de diferentes tamaños.

Basado en tecnologías Qt y desarrollado en C++, AbanQ ha sido diseñado para proporcionar una solución empresarial robusta, escalable y personalizable. Su arquitectura modular permite a los usuarios seleccionar e implementar solo los módulos que necesitan, minimizando costos y complejidad.

### Características principales

- **Modular y escalable**: Adapta el software a tus necesidades específicas
- **Código abierto**: Contribuye y personaliza el software libremente
- **Multiplataforma**: Disponible para Windows, Linux y macOS
- **Gestión integral**: Contabilidad, facturación, inventario, y más
- **Documentos de negocio**: Facturas, albaranes, pedidos y reportes
- **Basado en Qt**: Interfaz gráfica moderna y responsiva

---

## Módulos disponibles

AbanQ ofrece una arquitectura modular que permite personalizar completamente la solución:

- **Contabilidad**: Registro y gestión de operaciones financieras
- **Facturación**: Creación y seguimiento de facturas y documentos de venta
- **Inventario**: Control de existencias y movimientos de almacén
- **Compras**: Gestión de órdenes de compra y proveedores
- **Ventas**: Gestión completa del ciclo de ventas
- **Tesorería**: Control de caja y flujo de efectivo
- **Informes**: Reportes personalizables y análisis de datos

---

## Tecnologías

- **C++**: Core del engine
- **C**: Componentes de bajo nivel
- **Qt Framework**: Interface gráfica multiplataforma
- **Qt Script**: Scripting para extensiones
- **PostgreSQL / MySQL / SQLite**: Soporte múltiples bases de datos

## Requisitos del sistema

- **Procesador**: x86 compatible
- **Memoria**: 512 MB mínimo (1 GB recomendado)
- **Espacio en disco**: 500 MB para instalación
- **Sistema operativo**: Windows XP+, Linux (cualquier distribución), macOS 10.5+
- **Base de datos**: PostgreSQL, MySQL, SQLite u otra compatible

## Casos de uso

AbanQ es ideal para:

- **Pequeñas y medianas empresas (PYMES)**: Solución económica y flexible
- **Negocios de retail**: Gestión de ventas, inventario y caja
- **Distribuidoras**: Control de pedidos, almacén y facturación
- **Servicios profesionales**: Facturación y control de proyectos
- **Empresas en crecimiento**: Escalable según necesidades

## Desarrollo

### Compilar desde fuente

```bash
# Clonar el repositorio
git clone https://github.com/falbujer/AbanQ.git
cd AbanQ

# Compilar
./engine/build.sh
```

### Estructura del proyecto

```
AbanQ/
├── engine/          # Motor principal (C++)
│   ├── src/        # Código fuente
│   └── build.sh    # Script de compilación
└── genesis/        # Módulos adicionales
```
